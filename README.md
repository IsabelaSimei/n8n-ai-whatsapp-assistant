# n8n-ai-whatsapp-assistant
Fluxo de trabalho automatizado no n8n que integra um agente de Inteligência Artificial (OpenAI GPT) com a plataforma Respond.io e APIs externas de e-commerce. O agente atua como assistente virtual de vendas, consultando catálogo de produtos por modelo/marca em tempo real, armazenando dados do contato e transferindo para um atendente humano.
